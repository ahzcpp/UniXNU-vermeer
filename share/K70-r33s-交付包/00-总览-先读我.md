# K70 跑 iPadOS —— r33s 交付包（成品 + 教学）

这个文件夹里有两样东西：**能直接测试的成品**，和**从零到成品的完整教学**。另附一份**未实验**的 GPU 驱动。

## 文件夹怎么看

| 文件夹 | 是什么 | 给谁 |
|---|---|---|
| **成品\** | `boot.img`（r33s 成品）+ 一键 `临时启动.ps1` + `刷机说明-给小白.md` | 想直接上机测试的人 / 小白 |
| **经验包\** | `K70-iPadOS-r33s-完整教程.md`（从零讲怎么找/改/写/修触控）+ `源码\`（我们自己写的全部源码） | 想学 / 想复刻 / 想交给别人做的人 |
| **GPU驱动-未实验\** | GPU（Adreno 740/Metal）离线工程，**没上过机** | 以后继续做 GPU 的人 |

## 两个最重要的提醒

1. **成品是临时启动**：`fastboot boot boot.img`，不刷分区，重启回原系统，不会把手机弄坏。
   但它要求**手机 userdata 里已经装好 iPadOS 根卷**（原作者那台测试机就是）。全新安卓机光有 boot.img 进不了桌面。
   详见 `成品\刷机说明-给小白.md`。
2. **GPU 那份没验证过**，r33s 没用它，不要当能用的东西。

## 成品能到什么效果

进 iPadOS 17.7.11 **简体中文锁屏/桌面**，**触摸能用**。已知不足：熄屏不回锁屏、图标偏大、背景/小组件因无 GPU 发黑发白、会掉电。

## 建议阅读顺序

- 只想测：`成品\刷机说明-给小白.md` → 跑 `成品\临时启动.ps1`。
- 想学/复刻：`经验包\K70-iPadOS-r33s-完整教程.md`（重点看第 3 章"构建方法论"和第 6 章"触控"）。
